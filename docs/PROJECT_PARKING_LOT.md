## 已知边界

- Chrome 和 Edge 数据独立。
- 同一浏览器不同 Profile 数据独立。
- 同一浏览器同一 Profile 的不同窗口共享收纳数据。
- 当前打开只展示当前窗口标签页。
- 如果关闭浏览器前已经收纳，可以通过收纳栏或 Sessions 恢复。
- 如果没有收纳就直接关闭浏览器，当前版本不保证恢复。

## 暂不处理的问题记录

1. 最近窗口快照  
   用于解决忘记收纳但想恢复上次窗口的问题。

2. 搜索  
   按标题、域名、URL、备注、标签搜索收纳内容。

3. 导出 / 导入 JSON  
   用于备份、迁移、跨浏览器手动转移。

4. 快捷键  
   快速收纳当前页、收纳并关闭、打开侧边栏。

5. Session 管理增强  
   Session 重命名、备注、归档、合并、排序、移除单个网页。

6. 数据迁移与健康检查  
   `store.version` migration、重复数据修复、孤儿 `sessionId` 修复。

7. 单个收纳前选择标签 / 状态  
   当前单个收纳主要支持备注，标签和状态可在收纳后编辑。

## 后续重新启动项目时的建议

后续重新启动时，不要直接进入开发。  
先阅读 `README.md` 和 `docs/PROJECT_PARKING_LOT.md`。  
再执行 `npm run test` 和 `npm run build`。  
确认 `dev` 最新状态后，再决定是否创建 P4 分支。  
P4 优先级建议：最近窗口快照 → 搜索 → 导出 / 导入。
